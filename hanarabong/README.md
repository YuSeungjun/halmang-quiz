# 하나라봉

제주 할망과 생활 속 표현을 익히는 열 문제 퀴즈와 제주어·표준어 문장 번역기입니다.

## 바로 열기

- **파일로 열기** — 이 폴더의 `하나라봉.html`을 브라우저에서 열면 인터넷 연결 없이 퀴즈, 수록된 예문의 양방향 조회, 저장된 문장의 낭독을 사용할 수 있습니다. 자유 입력한 문장의 AI 번역과 새 낭독에는 서버판이 필요합니다.
- **서버로 열기** — 프로젝트 루트에서 `sh hanarabong/run.sh`를 실행한 뒤 http://127.0.0.1:8766 에 접속합니다. 원격 SSH 환경에서는 편집기의 포트 탭에서 8766을 전달합니다. 서버는 한 판을 시작할 때마다 디스크의 최신 보기 검사 및 검토 상태를 읽습니다.
- 서버가 이미 실행 중인지 확인하려면 `tmux has-session -t hanarabong-quiz`를 사용합니다. SSH 종료 후에도 새로 실행해 두려면 `tmux new-session -d -s hanarabong-quiz 'sh hanarabong/run.sh'`를 사용합니다.

## 문장 번역과 듣기

상단의 **문장 번역**은 표준어를 제주어로 옮기는 방향으로 열립니다. 입력칸에 마우스를 올리거나 누르면 첫인사 예문이 비워집니다. 원문을 300자까지 적고 **번역하기**를 누르면 버튼 안에 예상 진행률이 표시됩니다. **초기화**를 누르면 번역 방향을 유지한 채 두 문장을 비우고 낭독을 멈춥니다. 가운데 화살표로 방향을 바꿀 수 있으며 **제주어 듣기**는 항상 제주어 문장 옆에 표시됩니다. 아래 찾아보기에서 고른 추천 문장은 입력칸을 다시 눌러 편집할 수 있습니다. [번역 화면 열기](http://127.0.0.1:8766/#translate)

등록된 낱말을 단독으로 입력하면 교육용 대표 표현과 출처를 먼저 보여줍니다. 예를 들어 ‘할아버지’의 결과는 ‘하르방’이고 제주어대사전에 실린 유의어도 표시합니다. 제주어 유의어를 입력해도 대응하는 표준어를 찾을 수 있습니다. 낱말 목록은 학습용 어휘와 방언사전에서 양쪽 대응이 하나인 짧은 풀이로 구성됩니다.

문장은 퀴즈에서 승인된 생활방언 예문을 먼저 확인합니다. 이어서 서버는 JIT의 제주어·표준어 학습용 텍스트, AI Hub 71558 훈련 라벨의 `dialect`·`standard`, 생활방언 원문·풀이를 검색합니다. 빈 문장과 마스킹된 문장 등을 제외하고 각 자료 안에서 중복을 합친 색인에는 JIT 126,687쌍, AI Hub 41,721쌍, 생활방언 428쌍이 있습니다. JIT 개발·테스트 세트와 AI Hub 검증 세트는 색인에서 제외했습니다. 일치하는 원문이 있으면 짝지어진 번역과 출처를 표시합니다. 새 문장은 관련 용례와 어휘 풀이를 로컬 Qwen3 32B에 전달해 번역하며, 원문과 번역 양쪽에서 확인한 낱말에는 출처를 연결합니다. 생성한 번역은 질문 어미와 문장 부호를 대조하고 같은 로컬 모델에 별도 요청을 보내 뜻·높임·지역 말투를 점검합니다. 문제가 있으면 한 번 고쳐 다시 확인하고, 통과하지 못하면 화면에 재입력 안내를 표시합니다. 이 과정은 자동 검사입니다.

표준어에서 제주어로 옮길 때 첫인사·자기소개·식사나 동행 제안에 해당하면 그 상황의 회화 문형도 참고합니다. 식사 제안에서는 함께 먹자는 표현과 상대가 먹을 의향이 있는지 묻는 표현을 구분합니다. [제주어연구소 인사말 풀이](https://www.jejueo999.kr/index.php/contents/qna?act=view&bd_bcid=qna&page=18&seq=2430) · [음식점 회화 수업](https://www.jejueo999.kr/index.php/contents/notice/class?act=view&bd_bcid=notice_class&page=7&seq=717)

“받아주시겠어요?” 같은 부탁과 “먹으러 가실래요?” 같은 제안이 이어지면 각 구절에서 누가 무엇을 할지 따로 확인합니다. 의도를 나타내는 ‘-젠’, 목적을 나타내는 ‘-레’는 제주어학교 회화 용례를, 정중한 부탁은 JIT의 ‘ᄀᆞᆯ아주시쿠과?’를 참고합니다. ‘사랑해요’에는 ‘소랑헴수다’가 쓰인 연구 예문도 제공합니다. [의도를 나타내는 ‘-젠’](https://www.jejueo999.kr/index.php/contents/notice/class?act=view&bd_bcid=notice_class&page=&seq=710) · [‘밥 먹으레 가카?’ 회화 수업](https://www.jejueo999.kr/index.php/contents/notice/class?act=view&bd_bcid=notice_class&page=&seq=787) · [임규홍, 「국어 방언 정도부사 연구」 예문 147](https://www.krm.or.kr/krmts/sdata/frbr/file/2008/KoreaUniv/pdf1/20081027133808398290.pdf)

최초 실행 시 `run.sh`가 SQLite 색인을 만듭니다. 자료를 갱신할 때는 프로젝트 루트에서 `python3 hanarabong/translation.py`를 실행합니다. 새 문장 번역은 `test/README.txt`에 있는 로컬 Ollama 서비스(`127.0.0.1:18765`, `qwen3:32b`)를 사용합니다. 듣기는 퀴즈와 같은 VoxCPM2 · AI Hub + JSS 체크포인트와 목소리 03으로 48 kHz WAV를 만듭니다. 처음 새 문장을 들을 때 모델을 GPU에 올립니다. 기본 GPU는 물리 장치 2이며 서버 실행 시 `CUDA_VISIBLE_DEVICES`로 지정할 수 있습니다.

오프라인 파일에서는 기본 낱말과 퀴즈 예문을 양방향으로 찾을 수 있습니다. 수록된 제주어 문장의 낭독도 파일 안에 들어 있습니다.

## 출제와 듣기

`catalog.py`는 연구실의 `QuestionLab.catalog_questions()`와 `read_state()`를 사용합니다. 현재 빈칸·표준어·보기·정답에 유효한 검사에서 단일 정답으로 판정된 문항 중 ‘수정 필요’를 제외합니다. 학습자용 API에는 문장 낭독이 준비된 문항만 포함됩니다. 기존 퀴즈와 같이 정답의 앞뒤 공백을 제거하고 NFC로 정규화해 묶은 뒤, 열 묶음에서 문항을 하나씩 뽑고 보기를 섞습니다.

이 버전에는 56문항, 서로 다른 정답 29개, 완성 문장 53개가 있습니다. 같은 문장을 서로 다른 낱말로 출제하면 문장 음성을 공유합니다. 각 문제에는 30초가 주어집니다. 문장 아래 막대와 초 표시가 줄어들고 5초부터 1초까지 매초 경고음이 울립니다. 마지막 2초는 짧은 두 음으로 바뀌고, 답을 고르거나 시간이 끝나면 경고음이 멈춥니다. 힌트를 읽는 동안에도 시간이 흐릅니다. 놀이 방법과 첫 장 이동 확인 창을 열면 타이머가 잠시 멈춥니다. 시간이 끝나면 정답을 확인하고 직접 다음 문제로 넘어가며, 해당 문장은 결과 화면에 ‘시간 초과’로 표시됩니다.

정답은 높은 두 음과 함께 해당 문장을 낭독합니다. 오답은 낮아지는 두 음을 내고 내가 고른 보기와 정답에 각각 풀이를 붙입니다. 보기의 뜻은 기존 출제 어휘와 방언사전에서 가져오고 정답에는 해당 문항의 문맥 풀이를 씁니다. 상단 소리 버튼은 효과음과 자동 낭독을 함께 조절합니다. 직접 듣기 버튼은 음소거 상태에서도 사용할 수 있습니다.

기존 연구실 퀴즈의 듣기는 제주특별자치도 생활방언 대화 전체의 원음입니다. 하나라봉의 낭독은 프로젝트의 마지막 학습 실험인 AI Hub + JSS 혼합 VoxCPM2가 합성한 문장별 WAV입니다. `training/runs/jeju_aihub_jss/20261118-voxcpm-sft/best.json`에서 선택한 step 2362와 기존 목소리 03 참조를 사용했습니다. 퀴즈 실행에는 GPU가 필요하지 않습니다.

문항이나 문장이 바뀌면 프로젝트 루트에서 다음 두 명령으로 문장 음성과 단일 파일을 갱신합니다. 합성할 때의 GPU 번호는 사용 가능한 장치로 지정합니다.

```sh
CUDA_DEVICE_ORDER=PCI_BUS_ID CUDA_VISIBLE_DEVICES=1 ~/.local/bin/uv run --no-project --python training/envs/voxcpm/bin/python python hanarabong/prepare_audio.py
python3 hanarabong/make_portable.py
```

## 확인

`verify.py`는 실제 서버에서 JIT와 AI Hub 예문 조회, 새 문장 양방향 번역, 제주어 문장의 브라우저 음성 재생, 오프라인 번역 범위를 확인합니다. 퀴즈 카탈로그와 음성 범위 요청도 검사하고 Chromium으로 시간 초과가 포함된 한 판과 화면 크기가 다른 세 판을 풉니다. Playwright가 설치된 Python으로 `python hanarabong/verify.py`를 실행합니다. 화면 캡처 위치는 `--screenshots`로 지정할 수 있습니다.

- 1440×900, 390×844, 320×568에서 첫인사와 시작 버튼이 첫 화면에 함께 보입니다.
- 실제 문항의 힌트, 정답·오답 반응, 보기 위치, 완성 문장, 정답 자동 낭독과 다시 듣기, 결과의 점수·오답 목록, 만점, 다시 풀기를 점검했습니다.
- 움직임 줄이기 모드에서 세 반응 모두 원본 팩의 정지 PNG를 사용합니다. 320px에서 아래아가 들어간 긴 보기의 줄바꿈도 별도로 확인했습니다.
- 단일 파일은 브라우저 네트워크를 끈 상태에서 360px 너비로 열 문제, 문장 음성, 오답 복습, 재시작을 확인했습니다.

## 자료

퀴즈의 제주어와 표준어 문장은 기존 카탈로그에 연결된 제주특별자치도 생활방언 자료입니다. 문제를 풀 때는 `이미지/기본_할망.png`가 표시되고, 첫 화면과 정답 반응에는 `이미지/halmang_quiz_motion_pack.zip`의 웃는 GIF를 씁니다. 사이트에서 웃음·힌트·오답 애니메이션의 60프레임은 1.5초에 한 번 반복됩니다. 움직임 줄이기 설정에서는 정지 이미지를 보여줍니다. 제주 풍경과 낱말 삽화는 이 화면을 위해 생성했습니다.

글꼴은 Pretendard, 나눔명조, 개구체입니다. 라이선스는 `test/public/fonts/LICENSE.txt` 및 `public/assets/*LICENSE.txt`에 있으며 단일 파일에도 포함했습니다. 음성 학습 자료와 출처는 `training/JSS_EXPERIMENT.txt`에 기록돼 있습니다.
